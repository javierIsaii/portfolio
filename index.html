Feel it looping

Descripción del proyecto

LoopState es una experiencia digital que explora la conexión entre sonido, imagen y emoción a través de piezas audiovisuales diseñadas como estados visuales en constante repetición. Cada “loop” representa una interpretación gráfica de una canción o atmósfera, creando una narrativa visual que evoluciona entre lo abstracto y lo emocional. El proyecto está concebido como una plataforma interactiva que posteriormente integrará elementos de realidad aumentada para transformar estos visuales en experiencias inmersivas.

Objetivo del proyecto

Desarrollar una plataforma web que funcione como base para una experiencia audiovisual interactiva, donde se integren recursos gráficos, animaciones y, en etapas posteriores, elementos de realidad aumentada que permitan al usuario interactuar con los visuales de forma inmersiva desde dispositivos móviles.
